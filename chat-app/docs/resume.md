# Nexus Chat Resume Content

## One-line project summary

Nexus Chat is a full-stack chat prototype demonstrating React, Django REST Framework, Django Channels, PostgreSQL, and real-time WebSockets.

## Resume bullet points

- Built a full-stack chat application with React/Vite frontend, Django REST API, and real-time WebSocket messaging via Django Channels.
- Implemented authentication with JWT, conversation membership controls, message threading, attachments, and read receipts.
- Prepared deployment-ready infrastructure with Docker Compose, production environment configuration, PostgreSQL support, and Redis channel layer integration.

## Recruiter-friendly description

Nexus Chat is a polished portfolio prototype that demonstrates full-stack development skills by combining a modern React UI with a Django backend and real-time chat capabilities. The project includes authentication, user profiles, private/group conversations, secure API design, and deployment preparation for Docker, Vercel, and Render.
