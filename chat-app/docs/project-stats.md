# Nexus Chat Project Statistics

## Estimated counts

- Number of APIs: 17
- Number of React components: 24
- Number of models: 5
- Number of serializers: 10
- Number of contexts: 4
- Number of WebSocket events: 5
- Architecture complexity: Medium
- Estimated development effort: 4-6 weeks

## Notes

- APIs include authentication, profile, user list, conversations, messages, and attachments.
- Components include pages, layout, chat UI, and common reusable elements.
- Models cover profiles, conversations, memberships, messages, attachments, and read receipts.
- Serializers support validation and output for accounts, users, chats, and messages.
- WebSocket events cover message send, typing start/stop, read receipts, and presence.
